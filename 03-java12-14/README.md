## 🧠 Module Summary

This is the **"preview era"** — many beloved modern Java features landed here first as previews before graduating to stable. The switch expression is a great example: it cleaned up one of Java's most verbose constructs. Text blocks made multiline strings (JSON, SQL, HTML) finally readable.
