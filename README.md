## 🎯 Goals

- Cover **every major Java release** from 8 to 25 with working code examples
- Understand **why** each feature was introduced, not just how to use it
- Build a **public reference** useful for interviews, reviews, and onboarding
- Share bite-sized insights as **social content** (LinkedIn / X / Dev.to)

---

## 🛠️ How to Use This Repo

1. Each module has its own `README.md` — start there for an overview
2. Code examples live in `/src` — runnable with standard `javac` / `java` or Maven
3. Deep-dive notes live in `/docs` — one `.md` file per topic
4. Each topic follows a consistent template (see [TOPIC_TEMPLATE.md](./TOPIC_TEMPLATE.md))
